# 🥥 Coco Nuts - Online Coconut Products Store

Coco Nuts is a full-stack e-commerce web application for selling coconut-based products online. The application provides product browsing, shopping cart, checkout, order management, and contact functionality.

## 🌐 Live Demo

**Live Website:** https://coco-nuts-store-2.onrender.com

**GitHub Repository:** https://github.com/Shyam211006/coco-nuts-store

---

## 📖 About

Coco Nuts is designed to provide customers with a simple and convenient way to explore and purchase coconut-based products.

The project uses a frontend built with HTML, CSS, and JavaScript, while the backend is developed using Node.js and Express.js. MongoDB Atlas is used to store product, cart, order, and contact information.

---

## ✨ Features

- 🏠 Responsive Home Page
- 🥥 Coconut Product Collection
- 📋 Product Details
- 🛒 Add to Cart
- ➕ Increase Quantity
- ➖ Decrease Quantity
- ❌ Remove Cart Items
- 💰 Automatic Total Calculation
- 📦 Checkout and Order Placement
- 📩 Contact Form
- 💾 MongoDB Database
- 🔐 Session-Based Cart
- ☁️ Render Deployment
